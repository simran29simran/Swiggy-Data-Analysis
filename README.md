# Swiggy-Data-Analysis
SQL Server – Project Introduction
This project focuses on analyzing Swiggy restaurant sales data using Microsoft SQL Server, covering data cleaning, data validation, duplicate handling, and relational data preparation. It also includes designing a Star Schema with fact and dimension tables to organize the dataset into a structured analytical model.

Using SQL queries, the project develops key performance indicators and explores business performance across revenue, order trends, restaurant performance, food categories, dish pricing, geographical distribution, and customer ratings. The analysis demonstrates how SQL Server can transform raw data into structured information and meaningful business insights to support data-driven decision-making.

Excel – Project Introduction
This project focuses on analyzing Swiggy sales data using Microsoft Excel to understand business performance through data cleaning, data preparation, KPI tracking, and interactive dashboard development. It covers sales performance, geographical trends, restaurant and food category analysis, pricing patterns, customer ratings, and time-based trends using Pivot Tables, Pivot Charts, and Excel formulas.

The project highlights key business metrics such as Total Sales, Average Order Value, Average Rating, Total Ratings, and Total Records. The interactive dashboard presents these metrics in a clear visual format, helping users explore sales patterns, compare business segments, identify trends, and derive meaningful insights for data-driven decision-making.
